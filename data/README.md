# Data provenance

These are static coursework datasets derived from an Our World in Data vaccination snapshot whose latest record is **9 March 2021**.

The map and comparison datasets use each country's latest available record within that snapshot. Reporting dates therefore vary by country; a value should not be interpreted as having been reported on 9 March unless that country's source record carries that date.

- `vaccinationsWorldwide.json` - country totals and calculated shares used by the choropleth.
- `vaccinationLollipop.csv` - country totals used by the lollipop chart.
- `top5PeopleVaccinated.json` and `top5TotalVaccinations.json` - leading-country and rest-of-world aggregates used by the donut chart.
- `world.topojson` - geographic geometry used by the choropleth.

Source: [Our World in Data COVID-19 data](https://ourworldindata.org/coronavirus-source-data).
